## Task 1: Close the 1 `Admitted` — `star_endpoint_bound_fiber`

**File:** `pgg-smc/reconstruct/rigidity_star_instance.v` (line 103)

**What:** Prove that for each sheet `s : 'I_(m.+3)`, the variation distance between the endpoint distribution and uniform is bounded by `2*(m+1)/(m+3)`.

**How:** Follow the proven `s5_endpoint_bound_fiber` in `rigidity_s5_instance.v` (lines 55–105). The proof structure:

1. Apply `var_dist_endpoint_image_bound_unbalanced` with `star_weval_inj1` to reduce to showing `1 < #|image|` for each sheet.
2. Case-split on `s`:
   - **s = 0 or s = 1** (center pair): The center generator `tperm(0,1)` moves s; any leaf generator `tperm(2, 2+i)` fixes s. Exhibit these two words → different images.
   - **s = 2** (star hub): Every leaf generator `tperm(2, 2+i)` moves s to `2+i`; the center generator fixes s. Exhibit center word vs any leaf word.
   - **s = 2+i for i > 0** (leaf target): The leaf generator `tperm(2, 2+i)` moves s to 2; the center generator fixes s. Exhibit these two words.
3. Each case: construct two explicit 1-words `w_a`, `w_b` such that `word_eval w_a s ≠ word_eval w_b s`, then apply `card_gt1P`.

**Difficulty:** The proof is parametric in `m` (unlike the concrete S_5 proof). The case split on `s` must handle the general ordinal structure `'I_(m.+3)`. Use `leqP` or `ltnP` to split `val s` into ranges `{0,1}`, `{2}`, `{3,...,m+2}`.

**Key reference:** `star_gen` definition in `pgg_raag_star.v` — center is `tperm n0 n1` (positions 0,1), leaf `i` is `tperm n2 (Ordinal (2+i))`.

**Epsilon computation for the bound:**
- Achievable(1) has `m+1` elements (one per generator).
- Worst case: sheet moved by only 1 generator → image has 2 values, distribution `(m/(m+1), 1/(m+1), 0, ..., 0)`.
- `var_dist = 2*(m+1)/(m+3)` matches the `var_dist_endpoint_image_bound_unbalanced` output with `k_min = 2`.

**Estimated LOC:** ~60–80 (proof only).

## Task 3: Dihedral group PGG instance

**New file:** `pgg-smc/groups/pgg_dihedral.v`

**What:** Define D_n as a PGG group instance: the group generated by an n-cycle σ and a reflection τ, acting on `'I_n`.

**How:**

1. **Define generators on `'I_n`:**
   - σ = `ncycle` (already in `pgg_abelian.v`)
   - τ = reflection: `τ(i) = (n-1-i) mod n` (reversal permutation)

2. **Prove basic properties:**
   - `τ` is an involution: `τ ∘ τ = id`
   - Conjugation: `τ * σ * τ = σ^(-1)`
   - `<<[set σ; τ]>>` is the dihedral group of order 2n

3. **Register as `MonodromyReprType`:**
   - `Dihedral_PGGTypes n := MkPGG {perm 'I_n} (n-1) <<[set σ; τ]>>`
   - `pgg_rho` = inclusion morphism (same as cyclic instance)

4. **Prove word-eval injectivity at L=1:**
   - Achievable(1) = {σ, τ} (2 generators)
   - `σ ≠ τ` because σ is a cycle and τ is a reflection
   - Use `vm_compute` on concrete small instances or prove generically

5. **Note:** MathComp's `extremal.v` has `'D_m` type and `Grp_dihedral` presentation. However, it constructs dihedral groups as abstract `finGroupType`, not as subgroups of `{perm 'I_n}`. We need the permutation representation, so we build it from `ncycle` + reflection.

**Structure:**
```coq
Section dihedral_perm.
Variable n : nat.  (* n.+2 to ensure N >= 2 *)
Let N := n.+2.

Definition reflect_fun (i : 'I_N) : 'I_N := rev_ord i.
(* or: Ordinal (ltn_pmod (N - 1 - i) ...) *)

Definition dih_reflect : {perm 'I_N} := perm reflect_fun_inj.

Definition dih_sigmas : 2.-tuple {perm 'I_N} := [tuple ncycle n; dih_reflect].

Definition Dihedral_PGGTypes := @Gen_PGGTypes 0 n dih_sigmas.
(* m=0 means Tg = m.+1 = 1... wait, Tg = ngens'+1 *)
(* Actually: ngens' = 1 (so Tg = 2), N = n.+2 *)
(* Gen_PGGTypes takes (m n : nat) where m = ngens'-1, so m = 1 *)
```

Wait — need to check `Gen_PGGTypes` signature. From `pgg_interface.v`:
- `Gen_PGGTypes` takes parameters determining `ngens'` and `N'`
- For 2 generators on N positions: `ngens' = 1`, `N' = N-1`

## Task 4: Direct product PGG instance

**New file:** `pgg-smc/groups/pgg_dprod.v`

**What:** Given two PGG instances `M1` on `'I_N1` and `M2` on `'I_N2`, construct a product instance on `'I_(N1+N2)` representing independent shuffles on disjoint sub-piles.

**How:**

1. **Embed permutations into the larger type:**
   - `lift_left : {perm 'I_N1} -> {perm 'I_(N1+N2)}` — acts on first N1 positions, fixes rest
   - `lift_right : {perm 'I_N2} -> {perm 'I_(N1+N2)}` — acts on last N2 positions, fixes first

2. **Key properties to prove:**
   - `lift_left` and `lift_right` are group morphisms
   - Their images commute: `commute (lift_left σ1) (lift_right σ2)` for all σ1, σ2
   - The generated subgroup is (isomorphic to) `G1 × G2`

3. **Register as `MonodromyReprType`:**
   - Generators = `[tuple of map lift_left gens1 ++ map lift_right gens2]`
   - Group = `<<[set lift_left g | g in G1] ∪ [set lift_right g | g in G2]>>`

4. **Main difficulty:** The ordinal arithmetic for `'I_(N1+N2)` splitting. Use `lshift`/`rshift` from MathComp (`fintype.v`) which provide:
   - `@lshift N1 N2 : 'I_N1 -> 'I_(N1+N2)`
   - `@rshift N1 N2 : 'I_N2 -> 'I_(N1+N2)`
   - `split_ordP` for case analysis

5. **MathComp's `gproduct.v`** provides `dprodE`, `dprod_card` for internal direct products, which can help prove group-theoretic properties once the embedding is set up.

**Estimated LOC:** ~300–400.

## Task 5: Mizuki-Sone XOR protocol instance

**New directory:** `pgg-smc/mizukisone2009/`
**New files:** `xor_group.v`, `xor_security.v` (minimum viable)

**What:** Formalize the 4-card XOR protocol (Mizuki-Sone 2009) as a PGG instance, following the den Boer pattern in `denboer1989/`.

**Protocol spec (4-card XOR):**
- N = 4 cards, positions 0,1,2,3
- Alice commits bit a at positions 0,1; Bob commits bit b at positions 2,3
- Committed format: bit 0 = ♣♥, bit 1 = ♥♣
- Shuffle: random cut from C_2 = ⟨(0 2)(1 3)⟩ (swap the two pairs)
- Output: XOR = a ⊕ b read from final pattern

**`xor_group.v` structure:**
```coq
(* Generator: σ = (0 2)(1 3) — swap both pairs simultaneously *)
Definition xor_sigma_fun (x : 'I_4) : 'I_4 := ...
Definition xor_sigma : {perm 'I_4} := perm (can_inj xor_sigmaK).

(* Involution: g = (0 1)(2 3) — swap within each pair *)
Definition xor_g_fun (x : 'I_4) : 'I_4 := ...
Definition xor_g : {perm 'I_4} := perm (can_inj xor_gK).

(* PGG instance: 1 generator on 4 positions *)
Definition xor_sigmas : 1.-tuple {perm 'I_4} := [tuple xor_sigma].
Definition XOR_M := @Gen_PGGTypes 0 2 xor_sigmas.
```

**`xor_security.v` structure:**
- Show C_2 = ⟨σ⟩ acts on `'I_4` (two orbits of size 2)
- Prove correctness: for all input pairs (a,b), the output pattern encodes a ⊕ b
- SecurityWitness: `uniform_security_witness` or `security_witness_fiber`

**Note:** The 4-card XOR protocol uses a smaller group (C_2 vs C_5 for den Boer). The security argument is simpler: C_2 has only 2 elements, so orbit analysis is elementary.

**Estimated LOC:** ~300–400 total across files.
