---
name: feedback_no_ambiguous_plan
description: Never leave "consider adding" or ambiguous alternatives in plans — make a decision
type: feedback
---

Never leave ambiguous phrases like "Consider adding..." or "Or: alternative approach" in plans. Make a concrete decision and list it definitively.

**Why:** User wants actionable plans with clear decisions, not open questions.

**How to apply:** When facing a design choice in a plan, pick the best option and state it as fact. If genuinely uncertain, ask the user via AskUserQuestion before writing the plan.
