# H003 — @composes chain does not reach a @main lemma within the commit

## Rationale

A helper lemma tagged `@composes` is only meaningful if its composition
chain eventually reaches a `@main` node. H003 is a warning-severity rule
that fires when a BFS traversal of the intra-commit `@composes` graph
starting from a helper lemma never reaches any `@main`-tagged lemma and
never leaves the set of entities present in the manifest (an edge that
exits the manifest is treated as "unknown" and suppresses the finding,
since the chain may be completed in another file outside the commit).

## Stages

- **Stage 1 only** (`comment_composes_reachability` branch). No Stage 2 agent required.

## Bad

```coq
(** a.  @composes: helper_b *)
Lemma helper_a : 0 < 1.
Proof. by []. Qed.

(** b.  @composes: helper_a *)
Lemma helper_b : 0 < 2.
Proof. by []. Qed.
```

Both helpers form a cycle that never reaches a `@main` node; both are flagged.

## Good

```coq
(** m.  @main correctness: the headline result. *)
Lemma headline : 0 < 1.
Proof. by []. Qed.

(** a.  @composes: headline *)
Lemma reaches_main : 0 < 2.
Proof. by []. Qed.
```

`reaches_main` composes directly into `headline`, which is tagged `@main`; no finding.
