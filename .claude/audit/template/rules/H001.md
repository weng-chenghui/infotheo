# H001 — Lemma/Theorem has no usable preceding comment

## Rationale

Peer review found many AI-written lemmas without any preceding comment.
Readers need a one-glance way to see what each lemma does and whether it
is a main result or a helper. H001 blocks any targeted entity that
either has no preceding comment block or whose block is degenerate
(empty, a single `TODO`, or a boilerplate header that does not describe
the entity).

## Stages

- **Stage 1**: `fast_check: missing_preceding_comment`. The helper walks
  upward from the declaration line, skipping blank lines (up to two) and
  decorator lines (`#[local]`, `#[global]`, `Arguments`, `Hint`,
  `Canonical`, `Coercion`, `Local`, `Global`, `Export`). A boundary line
  (`Section`, `Module`, `End`, `Require`, `Import`, `Open Scope`) stops
  the walk without success.
- **Stage 2**: the `rocq-auditor` agent inspects the captured
  `preceding_comment` for degeneracy. See `agent_prompt` for the metric.

## Targeting

- Always: `Lemma`, `Theorem`, `Fact`, `Corollary`, `Proposition`.
- `Definition` and `Fixpoint` only when body spans at least two lines,
  the declaration is not `Local`, and the right-hand side is not a
  single token.
- Out of scope: `Notation`, `Coercion`, `Canonical`, `Instance`,
  `HB.instance`, `Variable`, `Hypothesis`, `Axiom`, `Parameter`.

## Grace period

Controlled by `strict_comment_coverage` in `.claude/audit/config.yaml`.
Default `false`: only entities whose declaration line is in the staged
diff fire. Set to `true` to audit every touched file's entities.

## Bad

```coq
Lemma foo : 0 < 1.
Proof. by []. Qed.
```

```coq
(* TODO *)
Lemma bar : 0 < 1.
Proof. by []. Qed.
```

## Good

```coq
(** foo — 0 is strictly less than 1.
    Kind: helper.
    Why: used by bar_ge0 to discharge the base case.
    Used by: bar_ge0. *)
Lemma foo : 0 < 1.
Proof. by []. Qed.
```

## Known false-positive patterns

- A file-header coqdoc block attributed to the first lemma. The Stage 1
  scanner refuses to cross a `Section`, `Module`, `Require`, or `Import`
  line, which prevents this misattribution.
