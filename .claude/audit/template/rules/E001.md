# E001 — Proof continues after goal is already closed

## Rationale

Proofs that carry tactics after the goal has closed signal either
copy-paste residue or a misunderstanding of the closer. The audited
example is `E_enc_ce_contract` in `homomorphic_encryption/homomorphic_encryption.v`
where `apply (cpr_centropy ...)` closes the goal at line 311 yet the
proof continues through line 324, re-deriving a conditional-independence
fact that the closer already consumed.

## Stages

- Stage 2 identifies candidate terminator lines from the proof body.
- Tier K opens a rocq-mcp session at the claimed line and confirms no goals
  remain.

## Bad

```coq
Proof.
move=> ? ?.
apply (cpr_centropy (Y2:=X)(Y3:=E)) => c a b.
have Hpr : `Pr[ Z = c | [%X, E] = (a, b)] = `Pr[ Z = c | X = a].
  ...               (* twelve lines of derivation *)
move=> ?.
exact: Hpr.
Qed.
```

## Good

```coq
Proof.
move=> ? ?.
by apply (cpr_centropy (Y2:=X)(Y3:=E)) => c a b;
   exact: Hpr_or_equivalent.
Qed.
```

## Known false-positive patterns

- Proofs that close one subgoal with `by` and continue on another that the
  bullet structure makes clear. Tier K refutes these because `Show.` at the
  candidate line reveals the next subgoal.
