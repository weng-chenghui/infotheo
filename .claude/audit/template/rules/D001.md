# D001 — Unused Hypothesis or Variable in scope

## Rationale

In MathComp, a Section lemma only quantifies over the Variables and
Hypotheses that its proof term actually uses. An unused declaration either
signals dead code to remove or an intended strengthening that is not
justified by the proof. Tier K grounds the claim by re-proving with the
hypothesis removed.

## Stages

- Stage 2 produces the candidate finding based on textual body scan.
- Tier K invokes rocq-mcp to confirm the proof still closes without the
  hypothesis. A refuted candidate is dropped silently.

## Bad

```coq
Section Foo.
Variable n : nat.
Hypothesis n_gt1 : 1 < n.
Hypothesis n_gt0 : 0 < n.

Lemma foo_ge0 : 0 < n.+1.
Proof. by apply: ltn0Sn. Qed.
End Foo.
```

`n_gt0` and `n_gt1` are both unused.

## Good

```coq
Section Foo.
Variable n : nat.

Lemma foo_ge0 : 0 < n.+1.
Proof. by apply: ltn0Sn. Qed.
End Foo.
```

## Known false-positive patterns

- Hypotheses consumed by typeclass resolution or canonical structures that
  the surface proof does not mention directly. Tier K's kernel-level check
  catches these and refutes the candidate.
