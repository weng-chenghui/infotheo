# H002 — Role tag is malformed, empty, bad-label, or names a dangling @composes target

## Rationale

A role tag that carries an empty or degenerate value, references a label
not in `main_purpose_labels`, or points to a declaration that does not
exist in the repository is useless or misleading. H002 catches these
problems at Stage 1 via static checks and a bounded `git grep`.

## Stages

- **Stage 1 only** (`comment_tag_validity` branch). No Stage 2 agent required.

## Checks performed (all error severity)

1. **Empty or degenerate tag value** — `@intent` or `@main` carries a
   value that is blank, equals the identifier, or has fewer than 10 non-space
   characters with fewer than 2 alpha tokens.

2. **@main label not in enum** — the label word after `@main` is not in
   `main_purpose_labels` (`security`, `correctness`, `architecture`, `bound`).
   Missing label also fires.

3. **Dangling @composes target** — the target name after `@composes:` has
   no top-level declaration (`Lemma`/`Theorem`/`Fact`/`Corollary`/`Proposition`/
   `Definition`/`Fixpoint`) visible to `git grep` in tracked `.v` files.

4. **Wrong tag kind for declaration kind** — definitions must use `@intent`;
   lemmas must use `@main` or `@composes`, not `@intent`.

## Bad

```coq
(** @main security: x *)
Lemma empty_value_tag : 0 < 1.
```

Value `x` fails the content floor (too short).

```coq
(** @main leakage: this label is not in the enum at all. *)
Lemma bad_label_tag : 0 < 2.
```

`leakage` is not in `main_purpose_labels`.

```coq
(** @composes: nonexistent_xyz_target *)
Lemma dangling_composes : 0 < 3.
```

`nonexistent_xyz_target` has no declaration in tracked `.v` files.

## Good

```coq
(** @main security: abelian words leak no card identity. *)
Lemma well_formed_main : 0 < 1.
```

```coq
(** @composes: well_formed_main *)
Lemma well_formed_helper : 0 < 2.
```

`well_formed_main` is declared in the same file and visible to `git grep`.
