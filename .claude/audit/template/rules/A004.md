# A004 — `assert (...)` is non-idiomatic; prefer `have`

## Rationale

`assert (P) as H.` introduces a subgoal to prove `P` and then binds it to `H`.
SSReflect's `have H : P.` is the direct equivalent and composes with views,
terms, and the `:=` shortcut for proof terms.

## Stages

- Stage 1 fires on lines starting with `assert (`.

## Bad

```coq
assert (0 < n) as Hn.
{ by apply: ltnSn. }
apply: Hn.
```

## Good

```coq
have Hn : 0 < n by apply: ltnSn.
exact: Hn.
```

Or with a proof term:

```coq
have Hn : 0 < n := ltnSn _.
```

## Known false-positive patterns

- Comments or strings containing `assert(`. Handled by `ignore_in_comments`.
