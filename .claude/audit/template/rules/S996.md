# S996 — Stage 2 budget exhausted

S996 is a **driver-produced sentinel**: it is emitted by
`bin/stage2-agent.py` when the Stage 2 LLM audit hits one of three
caps and cannot run every chunk. No human-authored fixture can
trigger it, and no regex or agent prompt is attached. The
`stage_mode: sentinel` declaration in the catalog is what lets
`bin/lint-rules.py` no-op the fixture-parity check while still
asserting the good/bad stub pair exists.

## Three cap branches

- **daily_cap**: the cumulative token count recorded in
  `central-state/token-usage.json` for today's date has already
  exceeded `cfg.daily_token_cap` before the first chunk runs.
  Emitted from the pre-guard at `stage2-agent.py:330-340`.
- **token_cap**: the per-commit token budget
  `ROCQ_AUDIT_TOKEN_CAP` (fallback `cfg.per_commit_token_cap`)
  was exhausted mid-run. Chunks that did not run are deferred.
- **wall_cap**: the wall-clock budget `ROCQ_AUDIT_WALL_SECONDS`
  (fallback `cfg.wall_seconds`) was exhausted mid-run.

In all three branches `budget.stop_reason` carries the exact
trigger (`daily_cap`, `token_cap`, `wall_cap`) and the top-level
`stage2_incomplete: true` flag is set so `report-merge.py` can
render the `CAP HIT` banner.

## Why error severity

Earlier versions emitted empty findings (daily path) or an
`S999` info-severity finding (token/wall paths). Both cases
caused `report-merge.py` to exit 0 when a Stage 2 run was in
fact incomplete, silently downgrading a blocking verdict to a
pass. S996 at error severity closes that hole: any cap-hit
produces an error-severity finding, which makes `any_error` true
in the merge and forces exit 2.

## Resolution paths

1. Raise the triggered cap for this commit. For per-commit
   caps, set `ROCQ_AUDIT_TOKEN_CAP` or `ROCQ_AUDIT_WALL_SECONDS`
   inline with the `git commit` call. For the daily cap, edit
   `template/config.yaml`.
2. Reduce the size of the staged diff and retry. Smaller diffs
   produce fewer Stage 2 chunks.
3. Acknowledge the gap with `ROCQ_AUDIT_BYPASS=1`. The bypass
   writes S996 to `central-state/bypass.log` and
   `refs/notes/audit-bypass` so the incomplete-audit event is
   preserved in the commit's provenance.
