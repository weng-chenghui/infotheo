# A003 — Bare `auto`, `tauto`, or `intuition` as terminator

## Rationale

Bare `auto.` (and `tauto.`, `intuition.`) in an SSReflect proof is opaque: it
does not name what closed the goal and hides maintenance risks. The idiom is
`done.` for terminators or a named tactic when the user actually understands
the closer.

## Stages

- Stage 1 fires on lines that are only `auto.`, `tauto.`, or `intuition.`
  (optionally with whitespace and a period). Wrapped forms such as
  `by auto.` are deliberately allowed; they are common in Infotheo.

## Bad

```coq
auto.
```

```coq
intuition.
```

## Good

```coq
done.
```

```coq
by [].
```

```coq
by rewrite /foo; apply: leqnn.
```

## Known false-positive patterns

- `auto 10.` with an explicit depth — still opaque, deliberately flagged.
  Whitelist via a per-file pragma if a specific call site is justified.
